# 💧 « Dans quel pays investir pour maximiser l'impact sur l'accès à l'eau potable ? »

C'est la question que j'ai explorée dans mon dernier projet de Data Analytics.

Le scénario : une ONG dispose d'un budget limité et ne peut intervenir que dans **un seul pays** et sur **un seul axe d'action** :
- créer de nouveaux services d'eau ;
- moderniser les infrastructures existantes ;
- accompagner les décideurs publics.

Mon rôle était de transformer les données en recommandation.

## 📊 Les données

- 5 sources issues de l'OMS et de la FAO
- 194 pays étudiés
- Année de référence : 2016 (afin d'aligner tous les indicateurs sur une même période)
- Indicateurs : accès à l'eau potable, mortalité liée aux maladies WASH, stabilité politique et population

## ⚙️ Ma démarche

Avec Python, Pandas et Plotly, j'ai :

- nettoyé et fusionné les différentes sources de données ;
- construit des scores de priorisation adaptés à chaque type d'intervention ;
- analysé le compromis entre impact potentiel, risque et faisabilité.

## 💡 Quelques enseignements

- L'Afrique subsaharienne affiche un accès moyen à l'eau potable d'environ 67 %, contre 98 % en Europe.
- La fracture la plus marquée n'est pas seulement entre pays, mais entre zones urbaines et rurales.
- Les besoins diffèrent fortement selon les contextes : certains pays manquent d'infrastructures, tandis que d'autres disposent d'infrastructures qui restent insuffisamment performantes.

## 🎯 Recommandation finale

La Tanzanie ressort comme la priorité pour la création de services d'eau, avec près de 38 millions de personnes vivant en zone rurale sans accès adéquat à l'eau potable, dans un contexte relativement stable.

Cette expérience m'a rappelé qu'en data analyse, la valeur ne réside pas uniquement dans les visualisations ou les dashboards.

Le véritable livrable est la décision que les données permettent de prendre.
